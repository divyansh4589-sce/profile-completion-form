# Profile Completion Form

A responsive and accessible Profile Completion Form built using HTML, CSS, and JavaScript.

## Features

- Full Name Input
- Email Input
- Password Input
- Confirm Password Input
- Profile Completion Tracker
- Circular Progress Indicator
- Responsive Layout
- Accessible Form Labels
- Custom Focus States
- Modern UI Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

project/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How It Works

- Users enter details in the form fields.
- The completion percentage updates automatically.
- The circular progress tracker fills according to the number of completed fields.
- The UI follows accessibility best practices using labels and semantic form elements.

## Accessibility Features

- Proper labels for inputs
- Keyboard-friendly focus states
- Required field indicators
- Semantic HTML structure
